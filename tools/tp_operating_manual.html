tp — Tradier position & order manager (CLI)

Shell alias for python3 tools/tradier_positions.py. Manages live positions and working orders on a Tradier account directly from bash — list, close, add, modify, cancel, open. Single uniform verb-flag scheme. Sandbox vs production is picked by the DEVMODE flag in edge_lane_config.config.

1Flag scheme at a glance

The CLI follows a single rule:

-X <row>Short flag — operates on an EXISTING item from the table (row number from the list). --verb ...Long flag — opens a NEW position (single-leg via positionals, or multi-leg via ticket string).
OperationEXISTINGNEWFlag
List positions✓—tp (default)
List working orders✓—tp -O
Sell (close) position✓—tp -S <row>
Add to position✓—tp -A <row> -Q <qty>
Modify working order✓—tp -O <row> ...
Cancel working order✓—tp -C <row>
Closed-position P&L (daily)✓—tp -G [date|--since N]
Buy new (single-leg)—✓tp --buy SYM STRIKE EXP
Sell new (single-leg)—✓tp --sell SYM STRIKE EXP
Buy new (multi-leg, debit)—✓tp --buy '<ticket>'
Sell new (multi-leg, credit)—✓tp --sell '<ticket>'
tip Modifier flags — -L (limit price), -Q (quantity), -M (force market on modify), -D (duration), and --execute (required to actually submit) — work consistently across every operation.

2List positions

Default mode. Shows every open position grouped by spread. Multi-leg fills are aggregated back to one row by matching surviving positions against the originating filled multi-leg order.

Syntax

tp

Columns

ColumnMeaning
#Row number — use as the position-targeting argument for -S (close) and -A (add).
TickerUnderlying + structure shorthand (e.g. NVDA VE 220/225C, SPX IC 7300/7350P + 7450/7500C).
AcquiredDate/time the originating order filled, rendered in local timezone.
CostSigned net cash: + debit (you paid) or − credit (you collected).
Bid / AskCurrent absolute spread mark — what the spread is worth right now, always positive.
P&L $Unrealized P&L = current market value − cost basis. Green positive / red negative.
P&L %P&L as percentage of |cost basis|.
QtyOpen quantity (contracts for options, shares for equities).

4Close (sell) a position

Submit a closing order for a position by its row number from the list table. Defaults to a MARKET close at full quantity. Sides are flipped automatically (buy_to_open → sell_to_close, sell_to_open → buy_to_close).

Syntax

tp -S <row#> [-L <price>] [-Q <qty>] [--execute]

Flags

FlagRequired?Meaning
-S <row#>requiredPosition row number from tp list.
-L <price>optionalLimit price for the close. Omit for MARKET. Multi-leg uses type=credit|debit|even; single-leg uses type=limit.
-Q <qty>optionalQuantity to close. Defaults to full position size (partial close otherwise).
--execute / -xoptionalRequired to actually submit. Without it, runs PREVIEW-ONLY.

Examples

# Close position #3 at MARKET, full quantity (preview)
tp -S 3

# Close position #3 at LIMIT $1.20 (preview)
tp -S 3 -L 1.20

# Close 2 of 5 contracts at MARKET
tp -S 3 -Q 2

# Close 2 contracts at LIMIT $1.20 — live
tp -S 3 -L 1.20 -Q 2 --execute

5Add to an existing position

Open more contracts of an existing position, repeating its original sides (buy_to_open stays buy_to_open; sell_to_open stays sell_to_open). Order type matches the existing position's direction: credit position → credit order; debit position → debit order. -Q is required for add (number of contracts to add).

Syntax

tp -A <row#> -Q <qty> [-L <price>] [--execute]

Flags

FlagRequired?Meaning
-A <row#>requiredPosition row number to add to.
-Q <qty>requiredNumber of contracts to add (≥ 1).
-L <price>optionalLimit price. Omit for MARKET. Type is auto-determined from existing direction.
--executeoptionalRequired to submit. Without it, runs PREVIEW-ONLY.

Examples

# Add 2 contracts to position #3 at MARKET (preview)
tp -A 3 -Q 2

# Add 2 at LIMIT $1.30 (preview)
tp -A 3 -Q 2 -L 1.30

# Live add 5 to position #1 at $2.90
tp -A 1 -Q 5 -L 2.90 --execute
tip The original sides are inferred from the position's source order. For a bull-put credit spread, that means future adds will collect more credit (the short put resells; the long put rebuys), not flip into a debit. The order type also picks credit/debit automatically based on existing cost_basis sign.

6Open new single-leg position

Open a single option contract directly without an EdgeLane ticket. Three positional args after --buy or --sell: symbol, strike+side, expiration. Canonical OCC root lookup runs automatically — NDX → NDXP, SPX → SPXW, etc. The parent symbol on the order body stays as user-typed (NDX); the option_symbol field gets the canonical variant (NDXP).

Syntax

tp --buy <SYMBOL> <STRIKE+side> <YYYY-MM-DD> [-Q <qty>] [-L <price>] [-D <duration>] [--execute]
tp --sell <SYMBOL> <STRIKE+side> <YYYY-MM-DD> [-Q <qty>] [-L <price>] [-D <duration>] [--execute]

Positional args (in order)

ArgFormatExample
SYMBOLUnderlying ticker. Indices auto-route to their settlement-variant root.QQQ, SPY, NVDA, NDX
STRIKE+sideNumeric strike immediately followed by C (call) or P (put).746C, 540P, 220.5C
EXPIRATIONISO date YYYY-MM-DD.2026-06-04

Flags

FlagRequired?Meaning
-Q <qty>optionalNumber of contracts. Defaults to 1.
-L <price>optionalLimit price. Without it, order is MARKET.
-D <dur>optionalDuration: day / gtc / pre / post. Default gtc.
--executeoptionalRequired to submit live. Without it, runs PREVIEW-ONLY.

Examples

# Long call: buy 1 QQQ 746C exp 2026-06-04 at MARKET (preview)
tp --buy QQQ 746C 2026-06-04

# Long call at LIMIT, 2 contracts (preview)
tp --buy QQQ 746C 2026-06-04 -Q 2 -L 2.90

# Short put for credit (live)
tp --sell SPY 540P 2026-06-30 -L 1.50 --execute

# Day-only duration override
tp --buy NVDA 220C 2026-06-30 -L 4.50 -D day --execute

# Index option — canonical root auto-resolved (NDX → NDXP for PM-settled)
tp --buy NDX 30000C 2026-06-04 -L 50.00
bash quoting Strike+side is a single bareword token (no space between the digits and the C / P). Bash won't expand it; no quoting needed. Just remember the EXPIRATION must be in YYYY-MM-DD form — otherwise the parser rejects it.

7Open new multi-leg position

Multi-leg new positions use the same --buy / --sell flag with a single ticket-string argument — the exact format EdgeLane's "Copy ticket" button produces. Detection is automatic: if the first arg after --buy / --sell contains the · separator, it's parsed as a multi-leg ticket.

The ticket's own verb (Buy/Sell at the start) determines the order direction. Use --buy for debit (long) spreads and --sell for credit (short) spreads.

Leg side letter (P/C) may appear on just one strike — it's inferred for the rest, since a vertical/fly shares one side. So Long 30130 / Short 30030P, Long 30130P / Short 30030P, and 30130/30030P are all equivalent.

Syntax

tp --buy '<ticket-string>' [--execute]
tp --sell '<ticket-string>' [--execute]

Examples

# Credit spread — preview only
tp --sell 'Sell Balanced · SPX · 2026-05-21 · Short 7385P / Long 7365P · LIMIT credit $6.00 GTC · 1 contract'

# Iron condor — live
tp --sell 'Sell Range · NDX · 2026-05-19 · 7300/7350P + 7450/7500C · LIMIT credit $4.00 DAY · 1 contract' --execute

# Debit spread (long call spread)
tp --buy 'Buy Aggressive · NVDA · 2026-06-30 · 220/225C · LIMIT debit $1.80 GTC · 1 contract' --execute

# Bear put debit spread — DOUBLE quotes OK because the price has no $
tp -B "Buy Conservative · NDX · 2026-06-16 · Long 30130 / Short 30030P · LIMIT debit 15 GTC · 1 contract" --execute
bash quoting · the price The limit price accepts a bare number — LIMIT debit 15 GTC — so it works in plain double quotes.
A $ only works inside single quotes: in double quotes bash expands $15 → 5 (positional $1 + 5) before the tool runs, so the amount is wrong and unrecoverable. Either drop the $, or single-quote the whole ticket (required when pasting the "Copy ticket" string, which includes the $).
tip NDX / SPX / RUT / XSP tickets auto-route to their canonical OCC root (NDXP, SPXW, etc.) and the parent symbol on the order body stays as user-typed. This is the combination Tradier's order endpoint requires for index options.

8Modify a working order

Change the limit price, quantity, or order type on a still-working order. At least one of -L, -Q, or -M must be supplied. Tradier accepts the modify via PUT — the order ID stays the same.

Syntax

tp -O <row#> [-L <price>] [-Q <qty>] [-M] [--execute]

Flags

FlagRequired?Meaning
-O <row#>requiredWorking-order row number from tp -O.
-L <price>one ofNew limit price. Auto-promotes a market order to limit. Multi-leg keeps existing credit/debit/even direction.
-Q <qty>one ofNew quantity.
-Mone ofFlip the order to MARKET (drops price). Mutually exclusive with -L.
--executeoptionalSend PUT live. Without it, prints the PUT body and exits.

Examples

# Lower limit on order #2 from $1.50 to $1.30 (preview)
tp -O 2 -L 1.30

# Flip order #2 from LIMIT to MARKET (live)
tp -O 2 -M --execute

# Change quantity only — preserves existing type / price
tp -O 2 -Q 3

# Combine price + quantity, live
tp -O 2 -L 1.30 -Q 2 --execute

9Cancel a working order

Submit a DELETE to Tradier to cancel the order. Cannot be undone — once the cancel reaches the venue, that order ID is gone.

Syntax

tp -C <row#> [--execute]

Examples

# Preview: prints "DELETE accounts/.../orders/12345678" and exits
tp -C 2

# Live cancel
tp -C 2 --execute

10Closed-position P&L (daily)

Realized P&L on closures within a date range. Multi-leg spread closes are aggregated so a 4-leg iron condor close shows as one row, not four. The bottom of the table sums total cost, proceeds, and P&L for the range.

info Where the numbers come from. Tradier's /orders endpoint only returns the current trading day, and /gainloss only lists fully-settled closes (a position closed today doesn't appear there until it settles, next day). So tp -G merges sources, partitioned by date:
  • Prior days → /gainloss (settled, fully-closed history).
  • Today → live filled close orders, matched to their open to compute P&L (includes partial closes, which /gainloss never shows).
Prior-day opens closed today. If you close a position today that you opened on an earlier day, its open order is already gone from /orders, the position is gone from /positions, and it hasn't settled into /gainloss yet. tp recovers the cost basis from /accounts/{id}/history, looking back up to 7 days for the opening fills. Partial entries are averaged (qty-weighted) into one cost basis. These rows show the true open date in the Opened column. Use -V to see which source matched each close.

Syntax

tp -G [<YYYY-MM-DD>] [--since <N>]

Arguments

ArgDefaultMeaning
(no args)todayJust the current day's closures.
<YYYY-MM-DD>—Specific date.
--since <N>—Closures over the last N days (today − N → today).

Columns

ColumnMeaning
#Row index (informational only — these are CLOSED positions, no operations available on them).
TickerUnderlying + structure shorthand. Multi-leg closures aggregate (e.g. SPX 6000/6020P, NDX 7300/7350P + 7450/7500C).
ExpirationThe closed position's expiration date (the option-contract expiry, not the close date).
Opened / ClosedOrder-fill timestamps for entry and exit.
QtyContract count.
Cost / ProceedsTotal cash paid to open / received on close. Signs follow Tradier's convention (negative on credit collections).
P&L $Realized P&L = proceeds − cost. Green positive, red negative.
P&L %P&L as a percentage of |cost basis|.

Examples

# Today's closures + total realized P&L
tp -G

# Specific date
tp -G 2026-06-04

# Last 7 days
tp -G --since 7

# Last 30 days
tp -G --since 30

  1  SPXW 6000/6020P                       2026-06-20    2026-05-21   2026-06-04 14:30     1     −$175.00      −$80.00      +$95.00    +54.3%

tip This is purely informational — no row argument, no --execute, no destructive action. Safe to run at any frequency.

11Modifier flags & conventions

Modifier flags (apply to every operation)

FlagApplies toMeaning
-L <price>close / add / new / modifyLimit price. Omit for MARKET.
-Q <qty>close (partial) / add / new (contracts) / modifyContract count. For close, defaults to full size. For add, REQUIRED.
-Mmodify onlyForce MARKET on modify (clears price).
-D <dur>new single-legday / gtc / pre / post. Default gtc.
--execute, -xall destructive opsRequired to submit live. Without it, PREVIEW-ONLY.

Execute vs preview

All destructive actions (close, add, modify, cancel, open new) default to PREVIEW mode. Add --execute (or -x) to actually submit. This makes the same command-line safe as a dry-run dispatcher: paste, inspect, then re-run with --execute.

Sandbox vs production

Controlled by DEVMODE in edge_lane_config.config:

DEVMODE=true→ Tradier sandbox (api.sandbox.tradier.com) DEVMODE=false→ Tradier production (api.tradier.com)

Typos default silently to sandbox. The selected env is printed at the top of every command (env: production or env: sandbox) so you always know which account is being touched.

Order-type selection (automatic)

Tradier requires different type= values depending on whether the order is single-leg or multi-leg. The tool picks the right one automatically:

ScenarioSelected type=
No -L (market order)market
Single-leg with -Llimit
Multi-leg close, original was creditdebit (closing pays debit)
Multi-leg close, original was debitcredit (closing collects credit)
Multi-leg add, position is creditcredit (matches direction)
Multi-leg add, position is debitdebit (matches direction)
Multi-leg open via ticketWhatever the ticket's LIMIT credit|debit ... field says
tradier note The credit / debit / even order types are valid only on class=multileg. Single-leg orders (class=option or class=equity) must use type=limit. The tool handles this correctly under the hood — if you ever see "Invalid parameter, type: is not valid" from Tradier, that's a regression worth reporting.

12Installation & alias

Tradier credentials and DEVMODE flag live in edge_lane_config.config at the repo root. The tool reads them via tests/utils.py — no additional setup required if EdgeLane itself already works.

Make tp a shell alias

# One-shot — adds the alias to your bashrc
echo "alias tp='python3 /mnt/c/soljet_dev/EdgeLane/tools/tradier_positions.py'" >> ~/.bashrc
source ~/.bashrc

# Verify
tp -h

Or use a wrapper script (better arg-passing for complex strings)

mkdir -p ~/.local/bin
cat > ~/.local/bin/tp <<'EOF'
#!/usr/bin/env bash
exec python3 /mnt/c/soljet_dev/EdgeLane/tools/tradier_positions.py "$@"
EOF
chmod +x ~/.local/bin/tp

# Make sure ~/.local/bin is on PATH
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
